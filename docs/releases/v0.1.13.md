# CloudLedger v0.1.13

## Updates

- Added monthly financial analysis with member-level expense totals.
- Members in the monthly analysis can open a detailed view of their own
  completed expense transactions for the selected month, with a clear path
  back to the monthly summary.
- Added client-version checks and a server-enforced update gate. Clients below
  the configured minimum version are directed to the configured download page
  and cannot continue using business features until updated.
- Improved the operations upgrade flow so older deployments receive the client
  version configuration required by the update gate, and Turnstile probes send
  the client version when configured.

## Upgrade Notes

- No database schema or SQLx migration changes are required for this release.
- Deploy the four matching `v0.1.13` GHCR images together: server, PostgreSQL,
  Caddy, and network-anchor. Do not use Alpha or mutable image aliases for
  production.
- The release branch and packaged client use the production API. The `main`
  branch remains the testing line.
- Existing deployments must complete the controlled upgrade flow so client
  version settings are present before enforcing the minimum supported version.

## Validation

- Release-source policy tests and the deployment operations toolbox tests
  passed locally.
- Rust formatting, strict workspace Clippy, locked workspace tests, frontend
  production build, and release artifact checks are required in CI before the
  release is considered complete.
