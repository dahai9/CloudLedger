# CloudLedger v0.1.9

## Updates

- The packaged web and Android client now use the production API endpoint
  `https://cloudledger.513921.xyz`.
- This corrects v0.1.8, whose client package was mistakenly built with the
  test endpoint. Do not use v0.1.8 as a production client release.

## Upgrade Notes

- The backend schema and SQLx migration baseline are unchanged.
- Keep the production VPS configured with
  `CLOUDLEDGER_API_DOMAIN=cloudledger.513921.xyz`; the released client now
  targets the same endpoint.

## Validation

- Run Rust workspace, operations-toolbox, and release-policy tests.
- Build and publish matching server, PostgreSQL, Caddy, network-anchor, and
  signed Android artifacts from this release branch.
