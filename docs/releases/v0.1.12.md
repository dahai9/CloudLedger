# CloudLedger v0.1.12

## Updates

- Added daily and monthly ledger browsing with independent period controls.
- Added audit lifecycle views with dedicated transaction detail and cross-day
  assignment based on the latest audit step.
- Replaced platform-native date inputs with an in-app localized picker that
  keeps dates in the `Asia/Shanghai` time zone.
- Improved ledger and audit loading states and stabilized date-picker month
  transitions.

## Upgrade Notes

- No database schema or SQLx migration changes are required for this release.
- Deploy the four matching `v0.1.12` GHCR images together. Do not use Alpha or
  mutable image aliases for production.
- This release branch uses the production API; the `main` branch remains the
  testing line.

## Validation

- `cargo fmt --all -- --check`, strict workspace Clippy, and
  `cargo test --workspace --locked` passed locally. The PostgreSQL end-to-end
  test remains ignored because it requires a dedicated isolated database.
- The frontend production build, deployment-toolbox tests, and release-policy
  tests passed before promotion.
