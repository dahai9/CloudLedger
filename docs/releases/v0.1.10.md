# CloudLedger v0.1.10

## Updates

- Promotes the tested `v0.1.10.alpha.1` line to the formal `v0.1.10`
  production release.
- The packaged web and Android clients now use
  `https://cloudledger.513921.xyz`.
- The admin Turnstile widget is cleaned up before page rerenders, preventing
  duplicate widgets when switching login modes or retrying a failed login.

## Upgrade Notes

- The database schema and SQLx migration baseline are unchanged.
- Deploy the four matching `v0.1.10` GHCR images together; do not use Alpha or
  mutable `alpha` image aliases for production.
- Keep `main` on the testing endpoint. This production endpoint change exists
  only on `release/v0.1.10` and its formal tag.

## Validation

- `v0.1.10.alpha.1` Alpha workflow completed successfully.
- Release-policy and operations-toolbox tests passed before promotion.
- Formal CI will verify the matching release branch, app version, notes, signed
  APK, Rust workspace, and all four GHCR image manifests.
