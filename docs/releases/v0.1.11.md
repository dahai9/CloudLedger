# CloudLedger v0.1.11

## Updates

- Organization administrators can change their own backend password after
  verifying the current password.
- Platform administrators can reset an organization administrator password
  when the current password is forgotten.
- Password changes and resets revoke all existing sessions for the account and
  record organization-scoped security audit events without storing passwords.
- The production client uses the production API endpoint.

## Upgrade Notes

- The database schema and SQLx migration baseline are unchanged.
- Deploy the four matching `v0.1.11` GHCR images together. Do not use Alpha or
  mutable `alpha` image aliases for production.
- Keep `main` on the testing endpoint. The production endpoint change exists
  only on `release/v0.1.11` and its formal tag.

## Validation

- The `v0.1.11.alpha.1` workflow completed successfully after a transient
  GitHub action download retry.
- Password-management tests, workspace checks, and release-policy tests
  passed before promotion.
- Formal release CI will verify the matching release branch, app version,
  notes, signed APK, Rust workspace, and all four GHCR image manifests.
